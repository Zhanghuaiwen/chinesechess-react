> 源码：`Pikafish-master/`（官方 master 分支，2026 版）
> 编译产物：`Pikafish-master/release/`

## 一、编译结果

| 文件 | 说明 |
| ---- | ---- |
| `Pikafish-master/release/Pikafish.exe` | 编译好的 Windows 64 位引擎（静态链接，单文件） |
| `Pikafish-master/release/pikafish.nnue` | NNUE 神经网络权重（引擎必需，与 exe 同目录） |

- 编译器：MinGW-w64 GCC 16.2.0（winlibs，POSIX 线程 / UCRT），安装于 `D:\winlibs-gcc16`

- 运行：双击无法交互，请用命令行管道或象棋 GUI 调用（见下文"使用方法"）
- 自检输出：`Pikafish dev-20260812-nogit by the Pikafish developers`

## 二、接口：UCI 协议

引擎是一个**标准 UCI（Universal Chess Interface）引擎**：从**标准输入**逐行读命令，向**标准输出**逐行回结果。核心命令：

### 1. 初始化 / 握手

| 命令 | 引擎应答 | 说明 |
| ---- | -------- | ---- |
| `uci` | `id name ...` + 各 `option` + `uciok` | 查询引擎信息与可调参数 |
| `isready` | `readyok` | 查询引擎是否就绪（可反复调用） |
| `setoption name <Option> value <Value>` | — | 设置参数，如 `setoption name Threads value 4` |
| `ucinewgame` | — | 通知引擎开始新对局（清空哈希/历史） |
| `quit` | — | 退出 |

### 2. 摆局面

```
position startpos
position startpos moves h2e2 h9g7 ...   # 从初始局面 + 走法序列
position fen <FEN> [moves <uci> ...]    # 从 FEN 局面 + 可选走法序列
```

### 3. 让引擎思考

```
go depth 12          # 固定深度（必达）
go movetime 2000     # 固定思考毫秒数
go nodes 100000      # 固定节点数
go infinite          # 无限思考，等 stop
go wtime <ms> btime <ms> [winc <ms>] [binc <ms>] [movestogo <n>]   # 对局限时
go searchmoves h2e2 b2b3 ...  # 只从给定走法中选（须放行尾）
```

### 4. 结果输出

思考过程中引擎持续输出（每行一条）：

```
info depth 16 seldepth 24 multipv 1 score cp 45 nodes 123456 nps 500000 hashfull 12 tbhits 0 time 312 pv h2e2 h9g7 h2h6 ...
info depth 17 seldepth 26 multipv 1 score mate 3 nodes 200000 ...            # 发现杀棋
```

- `score cp 45`：局面分（厘兵/100 分制，**从当前行棋方视角**，正数即行棋方有利）
- `score mate N`：N 步杀（N 为回合数）
- 思考结束：

```
bestmove h2e2 ponder h9g7     # bestmove 后跟"建议走法"，ponder 为预估应手（可为空）
```

### 5. 调试命令（非 UCI 标准，官方附加）

| 命令 | 说明 |
| ---- | ---- |
| `d` | ASCII 棋盘 + FEN + 行棋方 |
| `eval` | 打印当前局面评估细节（含 NNUE 各层） |
| `bench` | 内置基准测试 |
| `export_net [file]` | 导出当前 NNUE 网络 |
| `flip` | 交换行棋方视角 |

## 三、棋盘：FEN 格式与棋子符号

标准中国象棋 FEN，共 10 行（行间用 `/` 分隔），行 1 为**黑方底线**、行 10 为**红方底线**。

**棋子符号**（红大写 / 黑小写）：

| 棋子 | 车 | 马 | 相/象 | 仕/士 | 帅/将 | 炮 | 兵/卒 |
| ---- | -- | -- | ----- | ----- | ----- | -- | ----- |
| 红 | R | N | B | A | K | C | P |
| 黑 | r | n | b | a | k | c | p |

示例（初始局面）：

```
rnbakabnr/9/1c5c1/p1p1p1p1p/9/9/P1P1P1P1P/1C5C1/9/RNBAKABNR w - - 0 1
```

字段：棋盘布局 ` 行棋方(w=红,b=黑)  走子计数  未吃子步数  回合数`（后三个引擎暂不强制，写 `- - 0 1` 即可）。

> 注意：引擎**拒绝"将可直接被吃"的非法局面**（`Unsupported position. King can be captured.`），因此下发给引擎的 FEN 必须是"将帅未受直接攻击"的合法局面（若当前就是被将军状态，`go` 前该局面仍合法——只要对方走完上一步后你的将正被将军，属于可接受局面；引擎指的是"轮到走的一方此刻能吃掉对方将"这种结束态）。

## 四、坐标系统（与应用棋盘互换的关键）

走法为 4 个字符 `源格 + 目标格`，每格 = `列字母 + 行数字`：

- **列 file**：`a`~`i`，对应应用的列 0~8
- **行 rank**：`0`~`9`，**rank 0 = 红方底线，rank 9 = 黑方底线**

与应用 `(row, col)` 的换算（应用 row 0 = 黑方底线）：

```
UCI 格 = (char)('a' + col) + (char)('0' + (9 - row))
应用格 = { row: 9 - (rank 数字), col: (file 字母 - 'a') }
```

对照示例：

| 应用坐标 | UCI 坐标 | 说明 |
| -------- | -------- | ---- |
| 红炮 (7,7) | `h2` | 起始位右下炮 |
| 红炮 (7,4) | `e2` | 起始位左炮 |
| 黑卒 (3,0) | `a6` | 黑左卒 |
| 帅 (9,4) | `e0` | 红帅 |

经典开局：`炮二平五` = 红炮 `h2e2`；`马8进7` = 黑马 `h9g7`。

引擎返回 `bestmove h2e2` 后，用上表反推即可得到应用的 `{from, to}`。

## 五、使用方法

### 方式 A：命令行手工交互

```powershell
# 管道方式（PowerShell）
("uci","isready","position startpos","go movetime 2000","quit") -join "`n" |
  .\Pikafish-master\release\Pikafish.exe
```

### 方式 B：接入象棋 GUI

任何支持 UCI 的中国象棋 GUI（如 楚汉棋缘、XQWLight、asXiangqi、Binghe 等）中"加载引擎"选择 `Pikafish.exe` 即可，NNUE 自动加载（须与 exe 同目录）。

### 方式 C：程序化调用（本项目 React 集成参考）

1. **原生（本地）**：Node/Python 等以子进程方式启动 `Pikafish.exe`，向 stdin 写 `position` / `go`，逐行解析 stdout 的 `info`/`bestmove`。适合桌面工具或本地服务。
2. **网页（推荐，纯前端）**：将引擎交叉编译为 **WASM**（Emscripten，`make build ARCH=wasm32 COMP=clang`），在 Web Worker 中跑 UCI，即可嵌入 React 应用。官方网页版即此方案。当前仓库已完成原生编译，WASM 编译可另行执行。

### 常用 UCI 选项

| 选项 | 默认 | 说明 |
| ---- | ---- | ---- |
| `Threads` | 1 | 搜索线程数，建议 = 逻辑核数 |
| `Hash` | 16 | 哈希表大小（MB） |
| `MultiPV` | 1 | 同时输出几个最佳走法（>1 用于分析） |
| `EvalFile` | `pikafish.nnue` | NNUE 文件路径 |
| `UCI_ShowWDL` | false | 输出胜率和预测 |
| `Move Overhead` | 10 | 网络/GUI 时延补偿（毫秒），防超时 |
| `Ponder` | false | 对方思考时是否继续思考 |
| `nodestime` | 0 | 用节点数代替计时 |

## 六、重新编译

依赖：winlibs MinGW-w64（已装于 `D:\winlibs-gcc16`）。

```powershell
# 一键重编（在 build/ 目录）
cd build
D:\winlibs-gcc16\mingw64\bin\mingw32-make.exe -f mingw.mk -j8
# 产物：build\Pikafish.exe；需把 pikafish.nnue 放到 exe 同目录
```

> 原厂 `src/Makefile` 面向 Unix 工具链（`uname`/`which`/`sh` 等），Windows 下直接用 `mingw32-make` 会失败，故提供了 `build/mingw.mk`。架构想换成 AVX2/AVX512 只需改 `CXXFLAGS` 里的 `-msse4.1 -DUSE_SSE41 -DUSE_POPCNT` 为对应开关（见 Makefile 第 742~886 行）。
